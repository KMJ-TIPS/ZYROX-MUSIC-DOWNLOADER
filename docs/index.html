GOOD TO KNOW

A few questions.
Straight answers.

Something else on your mind?
Ask on GitHub ↗

Does the app need an account or sign-in?+

No. ZYROX MUSIC works fully signed out — search, playback, downloads, local playlists, likes and recommendations all run on the device. Signing in is optional and only adds your existing YouTube feeds, library, history and comments.

Does it need an API key?+

No. ZYROX MUSIC is powered by the open-source NewPipe Extractor, so there is no API key to paste and nothing to configure. Install, open, press play.

Which APK should I download?+

Most phones from the last decade are arm64-v8a — start there. Older 32-bit devices need armeabi-v7a. Universal carries both architectures and works everywhere, at a larger file size.

Can the app update itself?+

Yes. The in-app updater checks the GitHub releases of this repository and picks the right APK for your device automatically, so updates are two taps away.

Which phones can install this APK?+

ZYROX MUSIC requires Android 11 or newer and ships as ARM builds distributed through GitHub releases. Android will ask for permission to install an app from outside the Play Store — that is normal for open-source apps.

Is it free and open source?+

Yes. ZYROX MUSIC is GPLv3 open source. The full source code, build instructions and license notices live in the GitHub repository, and third-party notices are listed in the repo and inside the app.

Can I build it myself?+

Absolutely. Clone the repo and run ./gradlew assembleRelease. The README documents Gradle commands, ABI splits and signing. Requires Android SDK (API 37) and JDK 17+.
